## Sobre o jogo

Kitsuna Tales of Spirits é um jogo 2D estilo metroidvania, desenvolvido em Unity com C#, inspirado na mitologia japonesa.

O foco do jogo é a exploração de um mundo interligado, com progressão não linear, novas habilidades, biomas diferentes, inimigos variados e bosses.

## Principais mecânicas

- Exploração de mapa com caminhos alternativos
- Recolha de itens e abertura de baús
- Checkpoints e progresso guardado
- Puzzles e combates contra inimigos e bosses
- Sistema de itens com ScriptableObjects

## Aspeto visual e técnica

- Sprites e animações criados em pixel art com LibreSprite
- Cutscenes para reforçar a narrativa
- Configurações e keybinds para melhorar a experiência do jogador
- Gravação de dados em ficheiros JSON
- Controlo de versões com GitHub e Git LFS para ficheiros grandes
