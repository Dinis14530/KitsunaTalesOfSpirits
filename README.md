## Sobre o jogo

Kitsuna Tales of Spirits é um jogo 2D no estilo metroidvania, desenvolvido em Unity com C# e inspirado na mitologia japonesa.

O jogo foca na exploração de um mundo interligado, progressão não linear, aquisição de habilidades, biomas variados e combates contra inimigos e bosses.

## Requisitos

- Unity Hub instalado
- Versão do Unity compatível com o projeto (ex.: 2022.3 LTS)
- Sistema operativo: Windows (recomendado)
- Git (opcional, para clonar o repositório)

## Como executar

1. Obter o projeto

	- Opção A — Clonar com Git:


	```bash
	git clone https://github.com/DinisAzevedo/KitsunaTalesOfSpirits.git
	```

	- Opção B — Download ZIP:

	  1. Fazer download do repositório no GitHub
	  2. Extrair o ficheiro ZIP para uma pasta local

2. Abrir o projeto no Unity Hub

	- Abrir o Unity Hub
	- Clicar em "Add project from disk"
	- Selecionar a pasta do projeto
	- Abrir com a versão do Unity indicada (ex.: 2022.3 LTS)

3. Abrir a cena principal

	- Navegar até `Assets/Scenes/`
	- Abrir a cena principal (ex.: `MainScene.unity`)

4. Executar no editor

	- Pressionar Play no Unity Editor para executar a cena dentro do editor.

## Build 

- Para gerar um executável, usar `File > Build Settings` no Unity e configurar a plataforma (Windows) antes de clicar em `Build`.
