# Visão Geral do Projeto

## Conceito

Kitsuna Tales of Spirits é um metroidvania 2D com foco em exploração, progressão por habilidades e narrativa inspirada na mitologia japonesa.

## Objetivos do projeto

- Entregar uma experiência jogável coesa para PAP
- Demonstrar competências de design, programação e produção
- Garantir base técnica sustentável para iteração

## Pilares

- Exploração não linear
- Combate com feedback claro
- Progressão significativa e recompensadora
- Identidade visual em pixel art
